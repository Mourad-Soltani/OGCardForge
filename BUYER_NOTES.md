# Buyer Notes - OGCardForge

**What you get:**

- Complete source code for OGCardForge CLI tool
- Offline Open Graph / social card generator (1200×630 PNG)
- Customizable title, description, author, accent color
- Health tests that pass
- MIT License
- Signature: Built by Mourad.Soltani

**How to run:**

1. Unzip the project
2. `cd OGCardForge`
3. `pip install -r requirements.txt`
4. `python -m ogcardforge --title "Hello World" --description "Generated offline" --output card.png`
5. Or `pytest tests/` to verify

**Requirements:**

- Python 3.9+
- Pillow (installed via requirements.txt)
- No external API keys or internet needed after install

**Ideal for:**

Indie hackers, content creators, developers who want consistent social previews without SaaS fees.
